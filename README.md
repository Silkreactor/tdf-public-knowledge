# TDF public knowledge

A small, public starting point for learning about **Traditional Dream Factory
(TDF)** and asking questions with your own AI.

**Starter edition 0.1 · 19 October 2026.** This first edition contains an index
and links to three public TDF website pages. It is a source-linked starting point;
it does not yet contain a reviewed, comprehensive knowledge base or offline copies
of the linked pages.

You can read these files without an AI. To use the starter with an AI, download
the single Markdown file and attach it, or copy its text into your conversation.
If your AI can browse, it can follow the public sources. If it cannot, the file
supplies links and a reading prompt, not the contents of those pages.

A useful first question is: **“Using these public sources, explain what TDF is,
show which page supports each point, and label what you cannot verify.”**
